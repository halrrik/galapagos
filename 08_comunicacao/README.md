# 08 — Comunicação

Esta pasta define padrões de linguagem, narrativa e identidade de comunicação da Versão Galápagos.

## Finalidade

Apoiar respostas, relatórios e apresentações com linguagem clara, executiva e orientada a decisão.

## Princípios de comunicação

- ser claro e objetivo;
- evitar jargão desnecessário;
- separar dado, leitura e recomendação;
- explicar restrições de forma sistêmica;
- evitar acusações pessoais;
- não maquiar riscos;
- não dramatizar problemas;
- adequar profundidade ao público-alvo.

## Estrutura sugerida para narrativa executiva

1. Contexto
2. Evidência
3. Leitura
4. Risco
5. Recomendação
6. Próximo passo

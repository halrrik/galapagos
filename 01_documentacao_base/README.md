# 01 — Documentação Base

Esta pasta reúne a documentação operacional estável da Versão Galápagos.

## O que entra aqui

- modelo operacional;
- fluxo de trabalho;
- hierarquia de demandas;
- políticas de fluxo;
- papéis e responsabilidades;
- rituais e cadências;
- ferramentas utilizadas;
- identidade dos relatórios.

## O que não entra aqui

- dados sensíveis;
- exports completos;
- prints de dashboards;
- informações pessoais;
- documentos internos não autorizados;
- diagnósticos pontuais de sprint.

## Regra

A documentação base deve descrever o funcionamento esperado do modelo. Quando houver mudança relevante, registrar no `PATCH_LOG.md`.

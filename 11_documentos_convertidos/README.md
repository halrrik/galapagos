# 11 — Documentos Convertidos

Esta pasta organiza documentos convertidos para Markdown e integrados ao Grimório — Versão Galápagos.

## Finalidade

Separar documentos convertidos de modelos operacionais, evidências, métricas e entregáveis.

Esta área deve receber materiais que vieram de documentos originais, como arquivos Word, PDFs, apresentações ou registros consolidados, após revisão mínima de formato e sensibilidade.

## Regras de uso

1. Todo documento convertido deve indicar origem, data de conversão e status de revisão.
2. Conteúdo sensível deve ser sanitizado antes de entrar no repositório.
3. Documentos ainda não revisados devem ficar em `99_revisar_antes_de_publicar/`.
4. O conteúdo convertido deve ser referenciado no índice e nas rotas quando virar fonte oficial de consulta.
5. A IA deve diferenciar documento convertido de interpretação, diagnóstico ou recomendação posterior.

# 99 — Revisar Antes de Publicar

Esta pasta guarda documentos convertidos que ainda precisam de revisão antes de virar fonte oficial do Grimório — Versão Galápagos.

## Uso esperado

Usar esta pasta quando o material:

- ainda não foi revisado;
- pode conter informação sensível;
- pode conter nomes, dados internos ou detalhes restritos;
- precisa de sanitização;
- ainda não tem destino definitivo.

## Regra

Nada nesta pasta deve ser tratado como fonte oficial sem revisão.

Antes de mover um documento para outra pasta, confirmar:

1. origem do documento;
2. data de conversão;
3. status de revisão;
4. sensibilidade do conteúdo;
5. pasta de destino;
6. necessidade de atualizar índice e rotas.

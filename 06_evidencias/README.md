# Evidencias

Esta pasta organiza materiais usados como apoio para leitura e analise.

## Tipos de material

- dashboards;
- prints;
- documentos de apoio;
- tabelas pequenas;
- registros pontuais.

## Regra principal

Evidencias sao registros de um momento. Elas ajudam a explicar uma situacao, mas nao devem ser tratadas como verdade permanente.

## Como registrar

Sempre que possivel, indicar:

- data;
- origem;
- time ou area;
- periodo analisado;
- observacoes;
- limites conhecidos.

# Diagnostico de Maturidade

## Quando usar

Usar para avaliar evolucao operacional de um time, area ou frente.

## Entradas desejadas

- contexto;
- evidencias;
- praticas observadas;
- pontos fortes;
- pontos de atencao;
- recomendacoes.

## Estrutura sugerida

1. Resumo
2. Dimensoes avaliadas
3. Evidencias
4. Leitura atual
5. Recomendacoes
6. Proximos passos

## Regra

Maturidade deve ser usada como mapa de evolucao, nao como ranking.

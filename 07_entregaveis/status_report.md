# Status Report

## Quando usar

Usar para comunicar andamento de uma iniciativa, frente ou entrega relevante.

## Entradas desejadas

- nome da iniciativa;
- objetivo;
- periodo;
- status atual;
- progresso;
- pendencias;
- riscos;
- proximas acoes.

## Estrutura sugerida

1. Contexto
2. Status atual
3. Avancos
4. Pendencias
5. Riscos
6. Proximas acoes

## Regra

O texto deve ser claro, executivo e orientado a decisao.

# 07 — Entregáveis

Esta pasta define os formatos de saída apoiados pela Versão Galápagos.

## Entregáveis previstos

- relatório de sprint;
- status report;
- apresentação executiva;
- plano de melhoria;
- roadmap;
- documentação de processo;
- resposta de e-mail;
- diagnóstico de maturidade.

## Estrutura recomendada para cada entregável

Cada modelo deve indicar:

- quando usar;
- entradas necessárias;
- ordem de análise;
- formato de saída;
- cuidados;
- validação final.

## Regra

Todo entregável deve ser claro, rastreável e útil para decisão. Quando houver limitação de informação, ela deve ser declarada.

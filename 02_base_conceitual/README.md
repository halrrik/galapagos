# 02 — Base Conceitual

Esta pasta reúne os conceitos de referência usados pela aplicação Galápagos.

## Finalidade

Servir como camada de literatura e boas práticas para apoiar análises, diagnósticos e entregáveis.

## Temas previstos

- agilidade e fluxo;
- Scrum, Kanban e modelos híbridos;
- gestão de projetos;
- gestão de processos;
- gestão de pessoas;
- métricas base;
- governança;
- mudança organizacional.

## Regra

A base conceitual não deve ser usada como religião metodológica. Toda aplicação deve passar pelo `03_de_para_galapagos/`, que explica como o conceito é adaptado ao contexto local.
